A criterion is a choice, not a fact.

E-admissibility asks for one compatible belief at which an action ties for best. Strict pairwise maximality allows a different defending belief against each rival. Interval dominance compares separate expectation intervals. Pure-action maximin chooses the highest worst expectation. These answer different questions; this page does not select a criterion for you.

No pointwise-admissibility prefilter. Strict dominance needs a positive advantage under every compatible belief. A tie, including at a zero-mass boundary, is retained. Randomized rivals are exclusion certificates, not an enumeration of all mixed optimal actions or a recommendation to randomize.

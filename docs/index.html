The world list is the supplied logical universe. Removing a world is an assumption. Event bounds are constraints, not samples or confidence intervals. No independence is inferred unless the supplied constraints imply it.

Conditional bounds concern only compatible distributions with positive conditioning mass. If the event can vanish, that is shown separately. A forced-zero event has no conditional answer here. This does not implement de Finetti conditional coherence on null events.
